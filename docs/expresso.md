# Expresso dataset

## Overview

Expresso Telecom is an African telecommunications company that provides customers with airtime and mobile data bundles. 

The data from Expresso churn prediction challenge on Zindi describes 2.5 million Expresso clients in Senegal to  predict the likelihood of each Expresso customer “churning,” i.e. becoming inactive and not making any transactions for 90 days.

The Expresso dataset is representing customer behavior, service usage patterns, and revenue characteristics. Each row corresponds to a unique Expresso customer.

The dataset consists of customer-level variables describing recharge behavior, revenue contribution, usage activity, subscription patterns, geographic location, and service engagement metrics. 

expresso dataset contains  the train.csv file that  includes both numerical and categor ical features, consisting of 19 variables including 15 numeric variables and 4 categorical variables and 2,154,048 samples. 

The target is a column called CHURN that indicates if a client churned or did not churn.. 

It will help Expresso to better serve their customers by understanding which customers are at risk of leaving by determining the likelihood for a customer to churn - to stop purchasing airtime and data from Expresso.

## Variable definitions

| Parameter | Data type | Description |
| :---- | :---- | :---- |
| user_id | string | Unique identifier for the client. |
| REGION | string | The geographical location of each client. |
| TENURE | string | Duration of the client's subscription in the network. |
| MONTANT | double | Top-up amount deposited by the client. |
| FREQUENCE_RECH | integer | Number of times the customer refilled their account. |
| REVENUE | double | Monthly income generated by each client. |
| ARPU_SEGMENT | double | Average Revenue Per User over 90 days divided by 3\. |
| FREQUENCE | integer | Number of times the client has generated income. |
| DATA_VOLUME | integer | Total number of data connections or volume used. |
| ON_NET | integer | Count of inter-expresso (internal network) calls. |
| ORANGE | integer | Count of calls made to the Orange network. |
| TIGO | integer | Count of calls made to the Tigo network. |
| ZONE1 | integer | Count of calls made to Zone 1 international/special areas. |
| ZONE2 | integer | Count of calls made to Zone 2 international/special areas. |
| MRG | boolean | Indicates a client who is in the process of leaving (going). |
| REGULARITY | integer | Number of times the client has been active over a 90-day period. |
| TOP_PACK | string | The name of the most frequently activated service packs. |
| FREQ_TOP_PACK | integer | Number of times the client has activated the top pack packages. |
| CHURN | integer | Variable to predict - Target (1 if client leaves, 0 otherwise). |
